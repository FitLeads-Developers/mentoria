# NotebookLM: estudios y tu método

Habla en español, tutea, frases cortas. NotebookLM se usa en su web (https://notebooklm.google.com): aquí tú preparas los textos y los prompts para pegar, no manejas la web por el alumno.

## Dos usos

### 1. Un estudio → un podcast para tus clientes
1. El alumno crea un cuaderno y sube **un** estudio o guía fiable (PDF o enlace).
2. Comprueba con él que la fuente es seria (revista científica o guía oficial) y no una opinión.
3. Pega este prompt en la sección de resumen de audio, para personalizarlo:

```
Haz un podcast de unos 8 minutos para personas de 40 a 55 años que vuelven a entrenar tras una lesión
de rodilla. Tono cercano, sin tecnicismos (si usas uno, explícalo). Explica qué dice el estudio,
qué significa para ellas y qué NO se puede concluir. No des consejos médicos individuales.
```
4. Escucha el resultado antes de compartirlo. Un podcast generado con IA se presenta como tal.

### 2. Preguntas sobre tu propio método
1. El alumno sube sus documentos (método, protocolos, progresiones).
2. Prompts para pegar:

```
Según mis documentos, ¿qué criterios uso para decidir cuándo subir la carga a una persona con una
rodilla operada? Cita en qué documento está cada criterio.
```
```
¿Hay contradicciones entre mis documentos? Dime cuáles y dónde aparecen.
```
```
¿Qué preguntas frecuentes de clientes no quedan cubiertas por mi método?
```

## Avisos
- NotebookLM responde con lo que hay en las fuentes: si no está, debe decirlo. Si inventa, es una señal para revisar.
- Información médica: orientativa. Ante dolor o dudas, remitir al profesional sanitario del cliente.
