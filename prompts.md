# Prompts del curso

Para quien usa la app de Claude o ChatGPT sin el plugin. Copia, pega y cambia los datos entre corchetes. Ejemplo del curso: Marta, 45 años, rodilla operada, asesoría de 150–250 €/mes.

## Introducción
```
Voy a probar la IA en mis tareas del día a día. Ayúdame a elegir 3 tareas de mi trabajo como entrenador
y, para cada una, dime qué probar y cómo sabré si la IA ha ayudado o no. Anotar dónde no ayuda también vale.
```

## 1. Qué IA usar y cómo pedirle las cosas
Fórmula: contexto, tarea y formato.
```
Contexto: soy entrenador personal en [ciudad] y mi clienta Marta tiene 45 años, rodilla operada hace un año
y 3 horas a la semana para entrenar.
Tarea: hazme un plan de fuerza de 4 semanas.
Formato: tabla por semana con día, ejercicios, series y repeticiones. Marca qué debo consultar con su fisio.
```

## 2. Instalación: la app de Claude o Claude Code
```
Acabo de instalar Claude. Guíame en 3 pasos para hacer mi primera petición útil para mi negocio de
entrenador personal. Yo no soy técnico.
```

## 3. El cerebro de tu negocio
Sube a un Proyecto 5 documentos: negocio, método, clientes tipo, preguntas y objeciones, y tono.
```
Entrevístame de una en una para crear el documento "[negocio / método / clientes tipo / preguntas y objeciones / tono]"
de mi negocio de entrenador. Cuando tengas suficiente, escríbelo en un texto claro que pueda guardar.
```
```
Según los documentos del proyecto, ¿cuánto cuesta mi asesoría? Y dime también [un dato que NO está en los documentos]:
si no lo sabes, dilo.
```

## 4. Skills: lo que repites, conviértelo en una skill
```
Cada semana hago la revisión de un cliente: [describe cómo la haces]. Conviértelo en unas instrucciones
reutilizables (nombre, cuándo usarlo, pasos y formato de salida) para guardarlas como skill.
```

## 5. Tus conversaciones de WhatsApp
Exporta el chat y súbelo. Solo de clientes con consentimiento RGPD.
```
Aquí tienes el chat con una clienta. ¿Qué le he prometido y cuándo? Cita el mensaje de cada promesa
y dime cuáles no consta que haya cumplido.
```
```
Revisa este chat: ¿hay señales de que pueda darse de baja (tarda en responder, se salta sesiones, tono negativo)?
Dame las pruebas y un borrador de mensaje cercano, sin presión.
```

## 6. NotebookLM: estudios y protocolos
```
Haz un podcast de unos 8 minutos para personas de 40 a 55 años que vuelven a entrenar tras una lesión de rodilla.
Tono cercano, sin tecnicismos. Explica qué dice el estudio, qué significa y qué NO se puede concluir.
```
```
Según mis documentos, ¿qué criterios uso para subir la carga a una persona con una rodilla operada?
Cita el documento de cada criterio.
```

## 7. Contenido a partir de conversaciones reales
```
Estos son fragmentos de chats de clientes (con permiso). Quita nombres y datos personales. Busca las dudas que
se repiten y dame 3 ideas de contenido (formato, gancho de una línea y origen anonimizado). No escribas el guion.
```

## 8. De tu grabación a un reel editado
En ChatGPT o en la app de Claude puedes preparar el texto de los subtítulos; la edición con Remotion se hace en Claude Code.
```
Esta es la transcripción de mi vídeo de 30 segundos. Corrige errores, divídela en subtítulos de máximo 6 palabras
y marca en cada uno la palabra clave para destacarla.
```

## 9. Multiplicar y dar el toque "wow"
```
Describe un plano de recurso de 5 segundos para un reel sobre [tema]: lugar, luz, movimiento de cámara y qué se ve.
Que no aparezcan logos de marcas ni personas reales.
```
```
Para mi personaje de IA [nombre]: escribe la descripción fija (edad, rasgos, ropa) para pegarla siempre igual
en cada imagen que genere, y recuérdame etiquetarlo como creado con IA.
```

## 10. Conectores y MCP
Con Gmail, Calendar y Drive conectados:
```
Prepárame el día: mi agenda de hoy, los correos que necesitan respuesta (sin enviar nada) y, para cada cliente
con cita, lo último de su documento en Drive.
```

## 11. Rutinas
```
Quiero un informe cada lunes a las 8:00 con mi agenda de la semana, los correos pendientes y los clientes con
señales de baja. Solo lectura. Dime cómo programarlo como rutina.
```

## 12. Lead magnet con IA
```
En mis chats se repite: [problema, por ejemplo "miedo a volver a entrenar tras una operación de rodilla"].
Crea una guía de 1 página con título concreto, 3–5 pasos aplicables hoy, un aviso de que no sustituye a un
profesional sanitario y una llamada a reservar una valoración. Sin quiz y sin prometer resultados.
```
```
Ahora escribe el texto de la landing para descargar la guía: título, para quién es, qué recibe, formulario con
email y casilla de consentimiento, y botón.
```
